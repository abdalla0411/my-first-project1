## 📖 Project Overview

`my-first-project1` is a central workspace where I build, test, and document practical IT projects. It brings together three focus areas:

- **Web** – websites, landing pages, and small web tools.
- **Networking** – network designs, configurations, lab setups, and documentation.
- **Automation** – scripts and workflows that remove repetitive manual work.

Each upcoming project lives in its own folder, with its own notes and instructions, so the repository stays organized as it grows.

---

## 🤖 Workflow Separation

To stay focused and efficient, work is split between two AI assistants:

| Assistant | Responsibility | Examples |
|-----------|----------------|----------|
| **Gemini** | Daily tasks, emails, and planning | Drafting emails, to-do lists, schedules, project planning |
| **Claude** | Coding, architecture, and technical implementation | Writing code, designing system architecture, debugging, scripts, configs |

**Rule of thumb:**
- If it's about *organizing my day or communicating* → **Gemini**.
- If it's about *building or fixing something technical* → **Claude**.

## 📁 Folder Structure

```text
my-first-project1/
├── README.md              # Project overview (this file)
├── .gitignore             # Files and folders Git should ignore
│
├── web/                   # Web projects
│   └── project-name/
│
├── networking/            # Networking labs, configs, and diagrams
│   ├── configs/           # Device configurations (routers, switches)
│   ├── diagrams/          # Network topology diagrams
│   └── labs/              # Lab exercises and notes
│
├── automation/            # Automation scripts and workflows
│   ├── scripts/           # Python / Bash / PowerShell scripts
│   └── workflows/         # Scheduled or multi-step automations
│
├── docs/                  # Documentation, guides, and notes
│   ├── architecture/      # Design decisions and system architecture
│   └── planning/          # Plans and roadmaps
│
└── assets/                # Shared images, icons, and resources
```

> New projects should be added inside the matching category folder (`web/`, `networking/`, or `automation/`), each with its own short `README.md`.
